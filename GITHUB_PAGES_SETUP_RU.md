# Публикация TUTOR DESK через GitHub Pages (iPad)

## 1. Создать репозиторий
1. Откройте https://github.com/new в Safari и войдите в GitHub.
2. Repository name: `tutor-desk`.
3. Выберите **Public** (GitHub Pages на бесплатном плане обычно требует публичный репозиторий) и нажмите **Create repository**.
4. Не добавляйте автоматически README или другие файлы, так как они уже есть в проекте.

## 2. Загрузить файлы с iPad
1. Скачайте архив `TutorDesk-GitHub-Pages.zip` и распакуйте его в приложении «Файлы».
2. На странице нового репозитория выберите **Add file → Upload files**.
3. В приложении «Файлы» откройте распакованную папку и выберите файлы/папки проекта для загрузки. Если Safari не позволяет выбрать всю папку, загружайте содержимое частями; `index.html` должен находиться в корне репозитория, а не во вложенной папке.
4. Дождитесь завершения загрузки и нажмите **Commit changes**.

## 3. Включить GitHub Pages
1. В репозитории откройте **Settings → Pages**.
2. В разделе **Build and deployment** выберите **Deploy from a branch**.
3. Branch: `main`; folder: `/(root)`; нажмите **Save**.
4. Подождите несколько минут. GitHub покажет опубликованный адрес вида `https://ВАШ-USERNAME.github.io/tutor-desk/`.
5. Откройте этот адрес в Safari на iPad. Можно выбрать «Поделиться → На экран Домой».

## Важно
- GitHub Pages публикует только статический интерфейс. Облачные функции, Supabase Edge Functions и платёжная интеграция не разворачиваются автоматически GitHub Pages.
- Для работы облака нужно отдельно настроить Supabase, выполнить SQL из `cloud/` и развернуть функции из `supabase/`.
- Не загружайте в репозиторий пароли, Supabase service-role key, Paddle API key, webhook secrets или другие секреты.
- До подключения Supabase приложение работает с локальными данными браузера. Они не синхронизируются между устройствами автоматически.
- Это прототип. Перед публикацией для клиентов нужно отдельно проверить доступ к данным, RLS и Storage policies, удаление аккаунта и соответствие требованиям конфиденциальности.
